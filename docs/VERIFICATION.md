## 真实 SDK 与桌面端检查

- 在 Windows Harness Desktop 0.2.1-rc.3 上安装修复版，插件页显示组件“运行中”。
- 使用该桌面端内置的真实 SDK 编译全部 11 个工具，并验证省略 kind、ttlHours、limit 的调用通过；没有开启 idle 定时器或调用模型。
- 可运行 npm run check:sdk -- <实际 SDK 的 lib/index.js 绝对路径>；ASAR 内的 SDK 需使用桌面端 Electron 的 Node 模式执行。
- 本机已有的旧祖先 SDK 0.1.0-rc.8 也通过同一检查；不要求删除用户既有 SDK。
- 旧版 x => x 模拟 SDK 没有执行参数编译，因此漏掉 required:false 被拒绝的问题；本版新增真实 SDK 检查以覆盖此边界。
- 上述结果只证明安装、加载与 SDK 契约；不代表真实模型会按预期主动聊天。发布清单中的 desktopLiveVerified 仍为 false，保留完整端到端未验收状态。

## 版本与发布

目标宿主接口为官方 DeepSeek Harness 0.2.1-rc.3。
包声明的 compatible 是目标版本约束，不是厂商认证或实机通过证明。
npm run release 会重新运行测试、语法检查，再离线 npm pack，
生成源码 ZIP 和带版本号的 SHA-256 清单。不创建任何远端仓库。
