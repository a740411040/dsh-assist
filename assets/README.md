# Rice-loving whale-girl mascot

The README mascot is an AI-generated illustration created with the built-in image generation tool, using the [community DeepSeek rice meme](https://aigengtu.com/zh/meme/303) as a visual reference. The reference informs the blue hair, whale features, navy-and-white outfit, and rice bowl; the generated illustration uses a new pose and composition. It is not an official DeepSeek mascot or endorsement. The source reference image is not redistributed in this repository.

`fish-daughter.png` is the transparent PNG used by the project README. Keep this directory with the README when distributing the source or package.
